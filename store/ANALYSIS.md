## نقاط القوة
- موقع نظيف، RTL ممتاز، تصميم أخضر احترافي.
- SEO أساسي موجود (Rank Math).
- منتجات حقيقية جاهزة (نباتات، بذور بطيخ F1، أسمدة AVAN، تايمرات أوربت، ملش...).
- أسعار منخفضة (0.5 – 5.5 ر.ع) = سهولة الشراء المتكرر.
- واتساب واضح + Google Analytics + Ads.
- وصف المنتجات موجود (مثال الألوفيرا جيد نسبياً).

## نقاط الضعف (فرص تحسين سريعة)
1. **الأوصاف قصيرة/متشابهة** → تحتاج SEO أقوى + فوائد + كيفية الزراعة + CTA.
2. **صور المنتجات** قد تكون بحاجة لصور أكثر احترافية / خلفية بيضاء / lifestyle.
3. **لا توجد باقات (Bundles)** → اربط نبات + سماد + ملش = AOV أعلى.
4. **استرداد السلة** غير واضح (Klaviyo أو إيميلات Woo).
5. **المحتوى التسويقي** ضعيف (لا مدونة قوية، لا دليل زراعة).
6. **البحث المحلي** (Google My Business / خرائط عمان) غير مستغل بالكامل.
7. **الأسعار بالريال** جيدة، لكن أضف شارات "توصيل مجاني فوق X" أو "ضمان".
